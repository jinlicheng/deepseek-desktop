# JAI

**中文** | [English](README.en.md)

把常用的 AI 网页版装进一个桌面应用：一个窗口、多个标签、站点自定、下载统一。

> 非官方项目，与 DeepSeek、月之暗面（Kimi）、阿里（千问）等站点均无关联，也未获得其授权或认可。

## 功能

### 一个窗口，同时用好几个 AI

- 标签式聚合：同一窗口里开 DeepSeek、Kimi、千问、豆包……内置默认站点，也可以添加任意 http/https 网址
- 同时最多打开 9 个标签，配置列表本身不限长度
- 站内链接留在当前标签内打开，外部链接交给系统浏览器

### 站点随你配

- 增删改、调序，顺序就是标签顺序
- 启动时自动打开前 N 个（0~9），其余的收在标签栏「▾」里按需打开
- **拖拽排序**：标签栏里的标签随便拖（还没打开的站点不参与排序）；拖完的顺序会写回配置，所以下次启动的顺序跟你看到的一致
- **任何标签都能用 × 关掉**；只剩一个时 × 会置灰——至少留一个标签页

### 下载统一到一个目录

- 所有站点的下载都落到你指定的目录（默认用系统下载目录），在设置里随时改
- 可选「按站点建立子目录」；重名文件自动加 ` (1)`、` (2)`
- 下载完成时标签栏滑出一枚半透明小提示：**✓ 下载完成　立即查看　×**
  - 点「立即查看」直接在访达 / 资源管理器里定位到文件
  - 点「×」立即收起，不点的话 2.6 秒后自动消失

### 关闭不退出（系统托盘）

- 点窗口关闭按钮 → 收进系统托盘，不打断正在进行的回答
- 托盘菜单：**显示主窗口** / **退出**（只有从托盘退出才真正关掉应用）
- macOS 点 Dock 图标可唤回窗口；Linux 不启用托盘（关闭即退出）

### 标签栏入口

**⟳** 刷新当前标签 · **＋** 添加标签 · **▾** 打开已配置站点 · **⚙** 设置（点同一个按钮可收起面板）

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Cmd/Ctrl + 1~9` | 切到第 1~9 个标签 |
| `Esc` | 收起右侧面板 |

macOS 菜单栏还有「标签」菜单，内容与当前打开的标签同步。

## 使用

1. **第一次打开**：自带 DeepSeek 与 Kimi，登录即用（建议用手机号或扫码登录）
2. **加站点**：点标签栏「＋」，填名称和网址；勾选「保存到配置」，该站点下次启动仍在
3. **改站点**：点「⚙」改名、改网址、调序、删除，或设置「启动时自动打开前 N 个」
4. **改下载目录**：点「⚙」→ 下载目录 →「选择…」；想回到系统默认就点「默认」

配置文件 `tabs.json` 也可以手工编辑（应用下次启动生效）：

| 平台 | 路径 |
| --- | --- |
| macOS | `~/Library/Application Support/com.kelvin.jai/tabs.json` |
| Linux | `~/.config/com.kelvin.jai/tabs.json` |
| Windows | `%APPDATA%\com.kelvin.jai\tabs.json` |

## 获取安装包

仓库不附带预编译产物。推送到 `main` 分支（或手动触发）会跑 `build` 工作流，并行构建 macOS、Windows、Ubuntu 三个平台，产物在该次运行的 Artifacts 中下载。

> 安装包未做代码签名：macOS 首次打开需右键 → 打开；Windows 会弹出 SmartScreen 提示，选「仍要运行」即可。
>
> **只有 macOS 经过实际测试**：Windows 与 Linux 的安装包能正常构建（CI 三平台均通过），但还没有在真机上运行验证过。

## 本地运行（开发者）

```bash
npm install
npm run tauri dev
```

开发期建议只做 debug 构建（更快）：`npm run tauri build -- --debug --bundles app`。

## 已知事项

- **只在 macOS 上实际测试过**：Windows / Linux 的安装包能构建通过，但没有真机验证——欢迎在 issue 里反馈你在这些平台上的结果
- **Google 登录**在嵌入式窗口里会被 Google 拒绝（对方的安全策略，与本应用无关），请改用手机号或扫码登录
- Linux 使用 WebKitGTK，渲染兼容性弱于 macOS / Windows，个别页面可能有样式差异
- 界面文案目前只有中文
